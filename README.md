### 🙋 About me

Hi, I'm **aefly** 👋, a **system administrator**, **web developer**, **graphic designer** and **DevOps** engineer. I work across the whole chain, from the server to the last pixel, and I love understanding how things work under the hood to make them better.

- 🖥️ **System administration**: I run Debian servers, from setup and SSH access to security updates, backups, monitoring and bash automation.
- 🌐 **Web development**: I design and build modern, fast web apps with Next.js, React and Tailwind CSS, from the first layout to deployment.
- 🎨 **Graphic design**: I create visuals and 3D work in Photoshop, Affinity and Blender.
- 🐳 **DevOps**: I run my own self-hosted stack with Docker, Traefik and Portainer, and automate builds and releases with GitHub Actions.

<hr />

### 🧠 Interests

- 🎮 **Game modding**: taking games apart to see how they work
- 🔒 **Privacy**: keeping personal data out of places it shouldn't go
- 🐧 **Linux & servers**: building solid, secure infrastructure that just keeps running
- 🐳 **Self-hosting**: running my own services with containers and reverse proxies
- 🎨 **Graphic design**: turning ideas into visuals, from a quick sketch to a full 3D scene
- 🌍 **Open source**: reading great open-source code to level up, and publishing my own so others can too
